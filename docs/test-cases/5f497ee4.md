# Test Cases — Responsive Styling (FR-2)

## Requirements Under Test

| ID | Requirement |
|---|---|
| FR-2.1 | Page adapts via CSS media queries: desktop (≥768px) font 3–4rem; mobile (<768px) font 1.8–2.5rem + adjusted padding/margins. |
| FR-2.2 | No horizontal scrollbar on any device from 320px to 1920px. |

---

## Test Cases

### TC-2.1 — Desktop font size (≥768px)
- **Steps:** Open the page in a viewport ≥768px wide.
- **Expected:** The `<h1>` font-size is between 3rem and 4rem (inclusive).
- **Pass condition:** `getComputedStyle(h1).fontSize` resolves to a value in [3rem, 4rem].
- **Ties to:** FR-2.1

### TC-2.2 — Mobile font size (<768px)
- **Steps:** Resize viewport to 767px, 480px, 360px, and 320px widths.
- **Expected:** The `<h1>` font-size is between 1.8rem and 2.5rem (inclusive) at all widths.
- **Pass condition:** At each tested width, `getComputedStyle(h1).fontSize` is in [1.8rem, 2.5rem].
- **Ties to:** FR-2.1

### TC-2.3 — No horizontal scrollbar at 320px width
- **Steps:** Resize viewport to exactly 320px wide.
- **Expected:** `document.documentElement.scrollWidth <= window.innerWidth` (no scrollbar).
- **Pass condition:** No horizontal overflow. All content visible without side-scrolling.
- **Ties to:** FR-2.2

### TC-2.4 — No horizontal scrollbar at 768px width
- **Steps:** Resize viewport to exactly 768px wide.
- **Expected:** `document.documentElement.scrollWidth <= window.innerWidth`.
- **Pass condition:** No horizontal overflow.
- **Ties to:** FR-2.2

### TC-2.5 — No horizontal scrollbar at 1920px width
- **Steps:** Resize viewport to exactly 1920px wide.
- **Expected:** `document.documentElement.scrollWidth <= window.innerWidth`.
- **Pass condition:** No horizontal overflow.
- **Ties to:** FR-2.2

### TC-2.6 — Padding/margins adjust on mobile (<768px)
- **Steps:** Resize viewport to <768px.
- **Expected:** The `<body>` or `<h1>` has reasonable padding/margins (≥0.5rem) so text does not touch viewport edges.
- **Pass condition:** `getComputedStyle(body).padding` or `<h1>` computed margins keep the text at least 0.5rem from edges.
- **Ties to:** FR-2.1 (adjustment of spacing)

### TC-2.7 — Content not clipped or overlapped at breakpoint (768px)
- **Steps:** Resize viewport from 800px slowly down to 700px (crossing the 768px breakpoint).
- **Expected:** The heading remains fully visible, no part is clipped, and the transition is smooth (no layout break).
- **Pass condition:** At every width in [700px, 800px], the heading text is fully rendered and not overflowing its container.
- **Ties to:** FR-2.1, FR-2.2

### TC-2.8 — Word-break prevents overflow on very narrow screens
- **Steps:** Resize viewport to 320px.
- **Expected:** The word "Hello" and "Word" do not cause horizontal overflow; `word-break` or `overflow-wrap` is applied if needed.
- **Pass condition:** No text-induced overflow at 320px.
- **Ties to:** FR-2.2
