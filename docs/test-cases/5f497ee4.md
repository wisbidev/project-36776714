# Test Cases: Responsive Styling (5f497ee4)

## Source requirements
- **FR-2.1**: Media query breakpoint at 768px; desktop font 3–4rem; mobile font 1.8–2.5rem; padding adjusts.
- **FR-2.2**: No horizontal scrollbar across 320–1920px widths.
- Project memory: `overflow-x: hidden` on html/body; `word-break: break-word` on heading; `max-width: 100%` on heading.
- Deliverable: single `index.html` with embedded CSS, zero dependencies.

---

### TC-1 — Desktop font size (≥768px)
**Requirement**: FR-2.1  
**Check**: At viewport width ≥768px, the `<h1>` font-size is between 3rem and 4rem (inclusive).  
**Actual value in CSS**: `font-size: 4rem` (within range ✅)

### TC-2 — Mobile font size (<768px)
**Requirement**: FR-2.1  
**Check**: At viewport width <768px (e.g. 767px), the `<h1>` font-size is between 1.8rem and 2.5rem (inclusive).  
**Media query**: `@media (max-width: 768px)` sets `font-size: 2.5rem` ✅

### TC-3 — Very narrow screen font size (≤360px)
**Requirement**: FR-2.1  
**Check**: At viewport width ≤360px, the `<h1>` font-size is no smaller than 1.8rem.  
**Media query**: `@media (max-width: 360px)` sets `font-size: 1.8rem` (minimum of range ✅)

### TC-4 — Small phone font size (≤480px)
**Requirement**: FR-2.1  
**Check**: At viewport width ≤480px, the font-size progressively scales down (≤2.5rem).  
**Media query**: `@media (max-width: 480px)` sets `font-size: 2rem` ✅

### TC-5 — No horizontal scrollbar at 320px
**Requirement**: FR-2.2  
**Check**: At 320px viewport width, the page has no horizontal scrollbar.  
**CSS protections**: `overflow-x: hidden` on `html, body`; `word-break: break-word` and `max-width: 100%` on `h1`; `padding` on body adjusted in media queries. ✅

### TC-6 — No horizontal scrollbar at 768px
**Requirement**: FR-2.2  
**Check**: At 768px viewport width (breakpoint boundary), no horizontal scrollbar.  
**CSS protections**: Same overflow/width protections apply. ✅

### TC-7 — No horizontal scrollbar at 1920px
**Requirement**: FR-2.2  
**Check**: At 1920px viewport width, no horizontal scrollbar.  
**CSS protections**: Full-viewport layout with `max-width: 100%` heading and `overflow-x: hidden`. ✅

### TC-8 — Mobile padding adjustment
**Requirement**: FR-2.1  
**Check**: On mobile (<768px), body padding is increased/tuned so the text doesn't touch edges.  
**Media query**: `@media (max-width: 768px)` sets `padding: 1.5rem 1rem`; at ≤480px `padding: 1rem 0.75rem`. ✅

### TC-9 — Single-file delivery
**Requirement**: Constraint §4  
**Check**: All CSS is embedded in a `<style>` block within `<head>` of `index.html`.  
**Actual**: Yes — all CSS is in `<style>` inside `<head>`, no external files. ✅

### TC-10 — No external dependencies
**Requirement**: Constraint §4  
**Check**: No CDN links, no external stylesheets, no JS libraries.  
**Actual**: Zero external URLs in the document. ✅
