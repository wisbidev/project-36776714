# Test Cases — Static HTML Page

## FR-1.1 — Centered "Hello Word" heading

| # | Case | Expected | Requirement |
|---|---|---|---|
| TC-1 | The page displays the heading text "Hello Word" | `<h1>` contains the exact text "Hello Word" | FR-1.1 |
| TC-2 | Heading is centered horizontally | Body uses flexbox or grid with `justify-content: center` (or equivalent) | FR-1.1 |
| TC-3 | Heading is centered vertically | Body uses flexbox or grid with `align-items: center` (or equivalent) and `min-height: 100vh` | FR-1.1 |

## FR-1.2 — Pleasant visual style

| # | Case | Expected | Requirement |
|---|---|---|---|
| TC-4 | Background uses a pleasant color/gradient | A non-white, visually pleasant background is applied to the body (pastel, gradient, etc.) | FR-1.2 |
| TC-5 | Font is clean and readable | Font-family uses a readable system UI stack (e.g. `'Segoe UI', Tahoma, Geneva, Verdana, sans-serif` or similar) | FR-1.2 |
| TC-6 | Heading has appropriate sizing and spacing | `font-size` is defined for the `<h1>`, with `font-weight`, letter-spacing or text-shadow for polish | FR-1.2 |

## FR-1.3 — Valid HTML5 document

| # | Case | Expected | Requirement |
|---|---|---|---|
| TC-7 | DOCTYPE is HTML5 | First line is `<!DOCTYPE html>` | FR-1.3 |
| TC-8 | Required HTML tags present | File contains `<html>`, `<head>`, `<body>` tags | FR-1.3 |
| TC-9 | Has a `<title>` | A `<title>` tag exists inside `<head>` | FR-1.3 |

## FR-2.1 — Responsive font sizes

| # | Case | Expected | Requirement |
|---|---|---|---|
| TC-10 | Desktop font size (>=768px) is 3–4rem | `h1` font-size on desktop is between 3rem and 4rem | FR-2.1 |
| TC-11 | Mobile font size (<768px) is 1.8–2.5rem | `h1` font-size at mobile breakpoints is between 1.8rem and 2.5rem | FR-2.1 |

## FR-2.2 — No horizontal scrollbar

| # | Case | Expected | Requirement |
|---|---|---|---|
| TC-12 | No horizontal scrollbar at 320px width | `overflow-x: hidden` on body/html or tested via viewport; no content overflows | FR-2.2 |
| TC-13 | No horizontal scrollbar at 768px width | Same check at tablet width | FR-2.2 |
| TC-14 | No horizontal scrollbar at 1920px width | Same check at desktop width | FR-2.2 |

## Constraints

| # | Case | Expected | Requirement |
|---|---|---|---|
| TC-15 | No external dependencies | No CDN links, no `<link>` to external stylesheets, no `<script>` tags with external src | Constraint §4 |
| TC-16 | Single HTML file | All CSS is embedded in a `<style>` block within `<head>` | Constraint §4 |
| TC-17 | No JavaScript | No `<script>` tags at all | Constraint §4 |
